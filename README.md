# Jailbreak Changelogs Assets

This repository contains all static assets used for the Jailbreak Changelogs website. It is organized to support easy access and management of images, audio files, icons, and other resources for changelogs, contributors, and branding.

## Project Overview
Jailbreak Changelogs Assets is a centralized collection of media files for the Jailbreak Changelogs web project. It includes:
- Audio files for sound effects and horns
- Background images and overlays
- Contributor images and icons
- Logos and branding assets
- Miscellaneous images for changelogs, crews, items, robberies, seasons, and support

## Directory Structure
```
assets/
  audios/
    horns/                # Individual horn sound effects (MP3)
    horn_thumbnail_dark_bg.webp
    horn_thumbnail_light_bg.webp
  backgrounds/
    *.webp                # Background images
    vignette.png          # Overlay image
    png/                  # PNG versions of backgrounds
  contributors/           # Contributor images
  images/
    JBCLHeart.webp        # Heart icon
    Loading.gif           # Loading animation
    placeholder.*         # Placeholder images
    Robux_Icon.png        # Robux icon
    Season_Exp.png        # Season experience icon
    changelogs/           # Changelog images
    crews/                # Crew images
    items/                # Item images
    kofi_assets/          # Ko-fi support images
    robberies/            # Robbery images
    seasons/              # Season images
    support/              # Support images
  logos/
    JBCL_Long_*.webp/png  # Long logo variants
    JBCL_Short_*.webp/png # Short logo variants
    collab/               # Collaboration logos
    discord/              # Discord logos
    roblox/               # Roblox logos
favicon.ico               # Site favicon
index.html                # Main HTML file
styles.css                # Main stylesheet
CNAME                     # Custom domain config
vercel.json               # Vercel deployment config
```

## Asset Types
- **Audio Files:** MP3 sound effects for horns and other UI elements.
- **Images:** WebP and PNG formats for backgrounds, contributors, changelogs, and more.
- **Icons & Logos:** PNG/WebP for branding, favicon, and platform-specific icons.


## Usage
These assets are referenced by the Jailbreak Changelogs website and related projects. To use the assets:
1. Host this project on your own web server or preferred hosting platform.
2. Configure your own custom domain as desired.
3. Access all assets via your hosted domain, using the same directory structure.
  - Example: `https://yourdomain.com/assets/images/JBCLHeart.webp`
  - Example: `https://yourdomain.com/assets/audios/horns/Ahooga.mp3`
